# 命名与版本号规则

## 一、标准形式

```
<主题>V<主版本>.<次版本>.md
```

- `用户中心设计V1.0.md` ✅
- `用户中心设计 V1.0.md` ❌ V 前有空格
- `用户中心设计V 1.0.md` ❌ V 与数字之间有空格
- `user-center-designV1.0.md` ✅ 英文主题也允许
- `用户中心设计_v1.0.md` ❌ 小写 v + 下划线分隔

**唯一硬约束**：`V` + 数字 + `.` + 数字，紧贴在一起，前面是主题，后面是 `.md`。

## 二、解析

从文件名提取版本号，正则（不区分大小写，但输出统一大写）：

```
^(?<topic>.+?)V(?<major>\d+)\.(?<minor>\d+)$
```

步骤：

1. 去掉 `.md` 扩展名，得到 stem。
2. 用上面的正则匹配 stem。
3. 匹配成功 → `topic` / `major` / `minor`；失败 → 视为「无版本号」。
4. 新版本：`major` 不变、`minor + 1`；若 `minor` 原本是 9 → `major + 1`、`minor = 0`。

## 三、进位

| 当前 | 下一次 | 说明 |
|---|---|---|
| V1.0 | V1.1 | 正常 +0.1 |
| V1.8 | V1.9 | |
| **V1.9** | **V2.0** | 次版本满 9 进主版本 |
| V2.0 | V2.1 | |
| V2.9 | V3.0 | |

**不存在 `V1.10`**。看到 `V1.10` 说明有人把版本号当小数用了，按 `V2.0` 处理并在变更表注明。

## 四、非法写法对照

| 输入 | 处理 | 结果 |
|---|---|---|
| `设计v1.0.md` | 小写转大写 | `设计V1.0.md` |
| `设计V1.md` | 缺次版本 | `设计V1.0.md` |
| `设计V1.10.md` | 次版本越界 | `设计V2.0.md` |
| `设计V1.0.1.md` | 三段版本 | 取前两段 `设计V1.0.md`，提示原文件名不合规 |
| `设计V1.0-final.md` | 带后缀 | 去掉后缀 `设计V1.0.md` |
| `设计（最终版）.md` | 无版本语义 | 转 `设计V1.0.md` |
| `设计-2026-11-13.md` | 日期当版本 | 转 `设计V1.0.md`，日期写进变更表 |

规范化属于「修改文件名」的范畴，做完要更新引用，并在变更表里记一行「修正文件名格式」。

## 五、找最新版本

同目录可能有多个历史版本时，取版本号最大的那个：

```bash
# 列出所有带版本号的 md，按版本排序取最后一条
ls 用户中心设计V*.md 2>/dev/null | sed -E 's/.*V([0-9]+)\.([0-9]+)\.md/\1 \2 &/' \
  | sort -k1,1n -k2,2n | tail -1 | cut -d' ' -f3-
```

```powershell
# PowerShell 等价写法
Get-ChildItem '用户中心设计V*.md' |
  Sort-Object { [int]($_.BaseName -replace '.*V(\d+)\.(\d+)$','$1') },
               { [int]($_.BaseName -replace '.*V(\d+)\.(\d+)$','$2') } |
  Select-Object -Last 1 -ExpandProperty Name
```

**注意**：不能按文件修改时间判断——拷贝、解压、git checkout 都会重写 mtime。只认版本号。

## 六、改名

```bash
# 原地改名（保留 git 历史）
git mv 用户中心设计V1.2.md 用户中心设计V1.3.md

# 文件未被 git 跟踪时
mv 用户中心设计V1.2.md 用户中心设计V1.3.md
```

优先用 `git mv`：git 能识别为重命名而不是「删一个加一个」，历史可追溯。文件未被跟踪时会报错，退回普通 `mv`。

## 七、主题部分的写法

| 建议 | 避免 |
|---|---|
| `用户中心设计方案V1.0.md` | `用户中心 设计方案 V1.0.md`（空格） |
| `订单服务重构复盘V2.1.md` | `订单服务重构复盘-2026-11-13-V2.1.md`（日期进文件名） |
| `payment-retry-designV1.4.md` | `paymentRetryDesignFINALv1.4.md`（混用大小写与 FINAL） |

主题用中文或英文都可以，但**同一项目保持一致**：中文项目别混出英文文件名。
