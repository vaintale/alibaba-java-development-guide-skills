# 个人编辑偏好

> 跨项目的个人习惯，优先级低于 `project/<项目名>.md`，高于手册基线。
> 只记录**会影响编辑决策**的偏好，不是技术栈清单。

## 1. 我的习惯

| 方面 | 偏好 | 说明 |
|---|---|---|
| 金额 | BigDecimal / Long（分） | |
| Lombok | 用 `@Data` / 不用 / 仅 `@Getter` | |
| 异常风格 | 统一 `BizException` / 局部处理 | |
| 日志 | `@Slf4j` / 自研封装 | |
| Optional | 返回值用 / 仅内部用 / 不用 | |
| 注释 | 中文 / 英文 | |
| 单元测试 | JUnit5 + Mockito / Spock | |
| 参数校验 | `@Valid` + JSR303 / `Assert` | |
