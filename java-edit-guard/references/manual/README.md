## 引用格式

统一写作 `章节-(小节)序号【级别】`：

- `01-(七)4【强制】` → 第一章、第（七）节并发处理、第 4 条
- `04-2【强制】` → 第四章安全规约、第 2 条（该章无小节）
- `03` → 第三章整体

## 使用注意

1. **按需读取**：先看 `SKILL.md` §8 的路由表，只读命中的小节，不要整章载入。
2. **以原文为准**：社区流传的部分「阿里规约」与黄山版原文有出入，冲突时以本目录为准（典型差异见 `SKILL.md` §7）。
3. 内容由 PDF 转换而来，可能有少量排版噪声（多余空格、断行），引用时以语义为准。
