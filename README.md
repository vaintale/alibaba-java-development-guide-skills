# alibaba-java-development-guide-skills

围绕《Java 开发手册（黄山版）》构建的 Agent Skill 集合。

| Skill | 定位 | 何时用 |
|---|---|---|
| [`alibaba-java-development-guide-main/`](./alibaba-java-development-guide-main) | 手册检索器：按章节组织七大维度条文，含评测用例 | 查条文、写新代码、系统性 review |
| [`java-edit-guard/`](./java-edit-guard) | 编辑作业协议：编辑半径分级、契约清单、diff 噪声管控、四段交付说明 | 改存量代码、加参数、修 bug、重构 |

两者共用同一份手册底本，可同时安装。
